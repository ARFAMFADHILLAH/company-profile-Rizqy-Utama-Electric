# PRD: Web Company Profile Rizqy Utama Electric

## 1. Tujuan
Membuat web company profile & katalog produk profesional untuk **Rizqy Utama Electric** guna meningkatkan kredibilitas online, menampilkan layanan jasa kontraktor elektrikal, dan katalog produk/merk.

## 2. Tech Stack
- **Framework:** Next.js (App Router)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Bahasa:** Indonesia

## 3. Struktur Konten & Halaman
- **Navbar & Footer:** Logo resmi, navigasi cepat, kontak, sosial media.
- **Hero Section:** Slogan utama, CTA WhatsApp & Hubungi Kami.
- **Tentang Kami:** Profil perusahaan, legalitas, visi misi.
- **Layanan:** 
  - Panel Maker (LV/MDB/Distribution)
  - Instalasi Listrik (Industri & Komersial)
  - Maintenance & Trouble Shooting
- **Kategori Produk:**
  1. AC (Air Conditioner)
  2. Alat Ukur (Multimeter, Clamp Meter, dll)
  3. Pompa (Water Pump, Submersible, dll)
  4. Water Heater
  5. Alat Safety (APD, Helmet, Safety Shoes, dll)
  6. Material Elektrikal Lainnya (Kabel, MCB, Panel Box)
- **Merk / Brand Partner:** Menampilkan merk-merk terpercaya yang tersedia di toko/supplier.
- **Kontak & Lokasi:** Alamat, No Telepon, WhatsApp, Email, dan Google Maps.
- **Floating WhatsApp:** Tombol chat cepat mengambang di pojok kanan bawah.
